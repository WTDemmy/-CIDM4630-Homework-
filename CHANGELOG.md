## Format Guidelines

### Types of Changes
- **Added** for new features or homework assignments
- **Changed** for changes in existing functionality or assignment updates
- **Deprecated** for soon-to-be removed features
- **Removed** for now removed features
- **Fixed** for any bug fixes
- **Security** in case of vulnerabilities

### Version Format
- Use semantic versioning (MAJOR.MINOR.PATCH)
- MAJOR: Significant homework milestone or major refactoring
- MINOR: New homework assignment or substantial feature addition
- PATCH: Bug fixes, documentation updates, or minor improvements

### Entry Format
```
## [Version] - YYYY-MM-DD
### Added
- Description of what was added
### Changed
- Description of what was changed
```
